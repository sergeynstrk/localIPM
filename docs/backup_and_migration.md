# Инструкция: Перенос рабочего пространства и бэкап данных в LocalPM

### 1. Архитектура хранения
LocalPM использует технологию **IndexedDB** непосредственно в браузере вашего компьютера или телефона.
При запуске приложение автоматически запрашивает режим **Persistent Storage** (Постоянное хранилище), защищающий базу данных от автоматической очистки браузером при нехватке места на диске. Индикатор статуса защиты отображается в левом нижнем углу строки состояния.

---

### 2. Полное резервное копирование рабочего пространства
Для сохранения всех проектов, настроек и календарей в единый файл:
1. В правом верхнем углу шапки нажмите кнопку **«Резервная копия»** (📥).
2. Браузер автоматически скачает файл вида:
   `localpm-workspace-backup_ГГГГ-ММ-ДД.json`
3. Храните этот файл на флешке, сетевом диске или в личном архиве.

---

### 3. Восстановление рабочего пространства
Для восстановления рабочего пространства из ранее сохраненного файла:
1. В правом верхнем углу нажмите кнопку **«Восстановить»** (📤).
2. Выберите файл `localpm-workspace-backup_*.json`.
3. Система восстановит все проекты, задачи, зависимости и календари.

---

### 4. Перенос приложения на другой компьютер
1. Скопируйте всю папку `localIPM` на USB-накопитель или отправьте архивом.
2. Скопируйте файл резервной копии `localpm-workspace-backup_*.json`.
3. На новом компьютере запустите `start.cmd` или откройте `index.html`.
4. Нажмите «Восстановить» и укажите файл бэкапа. Все ваши проекты будут мгновенно развернуты.
