# Руководство пользователя LocalPM (v2.1)
## Автономный локальный планировщик проектов (Offline-First PWA)

### 1. Назначение и запуск
LocalPM — это полноценное клиентское (serverless) веб-приложение для календарно-сетевого планирования проектов по методу критического пути (CPM) с диаграммой Ганта и WBS.

- **Запуск на ПК (без установки)**:
  - Дважды кликните `start.cmd` или откройте файл `index.html` в браузере Chrome / Edge / Firefox.
  - При запуске через `start.cmd` запускается быстрый локальный сервер `http://localhost:8000`, открывающий все возможности PWA и Persistent Storage.
- **Работа на мобильных устройствах (Android)**:
  - Откройте веб-адрес приложения в мобильном браузере Chrome.
  - В меню браузера (три точки) выберите **«Добавить на главный экран»** (Установить приложение).
  - Приложение установится как автономный PWA и будет доступно без подключения к интернету.

---

### 2. Управление проектами
- **Создание проекта**: Нажмите кнопку `+ Новый проект` в верхнем меню. Укажите название, дату старта проекта и выберите календарь (пятидневка с праздниками РФ, стандартная пятидневка или 7 дней).
- **Переключение проектов**: Кликните по названию проекта в левом реестре проектов.
- **Удаление проекта**: Наведите курсор на проект в списке и нажмите `×` (с подтверждением).

---

### 3. Ведение плана и структура WBS
- **Добавление задач**:
  - Кнопка `+ Задача`: вставляет задачу ниже выбранной.
  - Кнопка `◆ Веха`: создает контрольную точку нулевой длительности.
  - Быстрая строка ввода (**Ghost Row**): в самом низу таблицы введите название и нажмите `Enter`.
  - Горячая клавиша `Insert`: создание новой задачи.
  - Горячая клавиша `Delete`: удаление выбранной задачи и связанных с ней зависимостей.
- **Иерархия WBS**:
  - `➔ Уровень` (Indent): делает задачу подзадачей предыдущей.
  - `⬅ Назад` (Outdent): поднимает задачу на уровень выше.
  - Суммарные задачи (Summary) автоматически рассчитывают свои даты начала и окончания по крайним датам дочерних задач.
- **Перемещение задач**:
  - Кнопки `▲` и `▼` на панели инструментов.
  - Горячие клавиши `Alt + ArrowUp` и `Alt + ArrowDown`.
- **Карточка задачи**:
  - Двойной клик на строку задачи или кнопка `📝 Карточка` на панели открывает полную форму задачи (наименование, длительность, % выполнения, дата, ответственный, связи, комментарии).
- **Поиск задач**:
  - Поле `🔍 Поиск задач...` в реальном времени подсвечивает совпадения в плане.

### 4. Связи и расчёт расписания (CPM)
В колонке «Связи» поддерживается полный синтаксис MS Project:
- `3` — связь типа FS (Окончание-Начало) с задачей №3, лаг 0.
- `3НС+2д` — FS с задержкой в 2 рабочих дня.
- `3НС-1д` — FS с опережением на 1 рабочий день.
- `4НН` — связь типа SS (Начало-Начало).
- `5ОО+3д` — связь типа FF (Окончание-Окончание).
- `6НО` — связь типа SF (Начало-Окончание).
- `2, 4НС+1д` — несколько предшественников через запятую.

Критический путь рассчитывается автоматически по методу полного резерва ($\text{Total Float} \le 0$) и подсвечивается на диаграмме Ганта ярким красным цветом.
При возникновении циклических связей система блокирует ошибку и информирует о цепочке цикла.

### 5. Импорт и экспорт данных
- **Импорт из Excel / CSV / TSV**:
  - Кнопка `📊 Импорт Excel / TSV`.
  - Поддерживается выбор файла `.xlsx` / `.csv` или быстрая вставка скопированных строк из буфера обмена (`Ctrl+V`).
  - Автоматическое распознавание заголовков колонок (русский и английский варианты).
  - Выбор режима: добавление к текущему плану или полная замена.
- **Выгрузка Excel (.xlsx)**:
  - Кнопка `Выгрузить Excel` формирует многостраничный файл с листами «План», «Вехи», «Связи» и «Сводка».
- **Печать в PDF**:
  - Кнопка `Печать PDF` открывает системный диалог печати. В настройках печати выберите «Сохранить как PDF». Печатный шаблон содержит колонтитулы, сводку проекта и диаграмму.
- **Экспорт диаграммы Ганта в PNG**:
  - Кнопка `PNG` на панели инструментов сохраняет текущий вид диаграммы в виде изображения высокого разрешения.

### 6. Передача проекта коллеге и возврат изменений (Peer-to-Peer)
Для передачи проекта без сервера и учетных записей:
1. **Отправка плана**: Нажмите `📤 Передать`, введите имя отправителя, получателя и комментарий. Будет скачан контейнер `<Имя-проекта>_<Дата>.lpmproject` с цифровой подписью SHA-256.
2. **Получение плана**: Коллега в меню слева нажимает `📥 Импорт от коллеги` и выбирает полученный файл. В его рабочем пространстве создается независимая копия проекта.
3. **Возврат изменений**: После внесения правок коллега нажимает `🔄 Возврат`. Формируется возвратный пакет.
4. **Сравнение версий (Diff)**: Автор исходного проекта открывает пакет возврата. Система отображает окно сравнения с подробным перечнем добавленных, измененных и удаленных задач и связей. Автор может нажать `Принять изменения` (прежняя версия автоматически сохраняется в бэкап) или `Отклонить`.
