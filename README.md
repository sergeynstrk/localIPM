# LocalPM (PWA v2.0) — Локальный планировщик проектов

Автономный (offline-first) инструмент календарно-сетевого планирования для ведения проектов с задачами, вехами, WBS-группировкой, 4 типами связей (FS, SS, FF, SF) с лагами, расчетом расписания по методу критического пути (CPM) и интерактивной диаграммой Ганта на Canvas 2D.

Приложение полностью клиентское (serverless): работает без бэкенда, не требует установки, все данные сохраняются локально в IndexedDB на устройстве и не передаются в сеть.

## Основные возможности

- **Диаграмма Ганта:** Адаптивная шкала (день, неделя, месяц, квартал), отображение связей линиями со стрелками, подсветка критического пути, вехи (ромбы) и прогресс выполнения.
- **Интерактивный сплиттер:** Плавное изменение ширины между таблицей задач и диаграммой Ганта перетаскиванием мыши.
- **Расчет расписания (CPM Engine):** Прямой (ES, EF) и обратный (LS, LF) проход, резерв времени (Total Float), автоматическая агрегация суммарных фаз (WBS Rollup), валидация и блокировка циклических связей.
- **Производственный календарь:** Учет пятидневной рабочей недели и праздничных дней РФ.
- **Импорт и экспорт:**
  - Импорт из Excel (.xlsx), CSV и мгновенная вставка из буфера обмена (TSV) с автоматическим распознаванием колонок.
  - Экспорт в Excel (.xlsx) с листами «План», «Вехи», «Связи» и «Сводка».
  - Печать в PDF через системный диалог браузера со специализированным печатным шаблоном.
  - Экспорт диаграммы Ганта в PNG высокого разрешения.
- **Передача проекта коллегам (\*.lpmproject):** Создание независимой копии проекта с метаданными и контрольной суммой SHA-256, экран сравнения версий (Diff) при возврате проекта автору.
- **Резервное копирование:** Экспорт и импорт полного рабочего пространства (все проекты и настройки) в один файл JSON.
- **PWA:** Поддержка работы в офлайн-режиме и установки на главный экран Android / десктоп.

## Запуск

Приложение является статическим сайтом. Достаточно открыть `index.html` в любом современном браузере или запустить локальный сервер:

```bash
python3 -m http.server 8000
```

Адрес: `http://localhost:8000`
